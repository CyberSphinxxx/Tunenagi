# Evidence file examples (NOT test results)

These are instructions, not passing proof. The only accepted check manifest is generated by `SCRIPTS/run_check.py`, never hand-written. For UI/device artifacts include screenshot/photo or `adb` diagnostic plus text steps, actual device API/model and a reference to the relevant `run_check` transcript. Auditors must reopen raw artifacts. Avoid screenshot/image generation masquerading as actual device screenshots.
