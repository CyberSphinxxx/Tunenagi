## 1. Why the output type is `ExternalTrack`

The repository already owns a provider-neutral remote-row model, `core/model/ExternalTrack.kt`
(committed before this task), and `core/library/SourceMatcher.kt` consumes it. `SPEC/ARCHITECTURE.md`
sketches `CatalogProvider.search(...): Page<ExternalTrack>`. An earlier draft of this slice invented
a parallel `NormalizedTrack` that generated a local `Track` and `TrackSource` per search result; that
would have duplicated the committed model and created database identity before any match or import
decision. The slice was rewritten to map onto `ExternalTrack`, which keeps the adapter boundary
honest and leaves local identity to the matching/persistence layer.

## 2. Entitlement semantics

- `is_delete = true` → `ProviderError.NotFound`. The resource is gone; it must not reach the matcher
  or be shown as merely unavailable. Not retryable, per the taxonomy.
- `is_streamable = false` → `ExternalTrack.availability = Restricted`, row **kept**. `SPEC/PROVIDERS.md`
  requires gated/paid/region-restricted tracks to be shown as unplayable rather than hidden or
  replaced; a search surface can render the row disabled and check `isPlayable` before resolving.
  This is a deliberate difference from deleted rows and is asserted directly.
- `is_streamable = true` → `availability = Available`, documented as the provider's claim. No stream
  URL is resolved here; TUN-0303 still resolves late and may fail.
- A blank provider id → `ProviderError.MalformedPayload`, so one bad row cannot throw at the
  `ExternalTrack` invariant or abort a page.

The parser's "absent flag is not yes" decision (TUN-0301) is preserved: a row without
`is_streamable` arrives as `false` and therefore as `Restricted`.

## 3. Attribution and missing metadata

- Provider display name → `artists = [name]`.
- Name absent, handle present → `[@handle]`; the handle is what Audius published and is not promoted
  to a fabricated display name.
- Neither → empty `artists`; no "Unknown" credit is invented.
- Missing title → `AudiusNormalization.UNTITLED_TITLE` ("Untitled"), which is also what the existing
  `ExternalTrack` test uses as an explicit placeholder.
- Zero/negative duration and blank artwork URLs are dropped rather than stored as invalid values.
- `providerAttribution = "Audius"` marks that the provider served the row.

## 4. Pages

`normalizePage` keeps provider order, counts parser skips plus rows this layer refuses in
`NormalizedPage.skipped`, keeps the raw `received` count and the provider's `nextOffset`, and exposes
`playableCount` so a UI can distinguish "nothing matched" from "rows were restricted". Restricted
rows stay in `items`; deleted and blank-id rows are counted, not silently converted into results.
