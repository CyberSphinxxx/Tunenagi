## Threats / API rights / privacy / accessibility checks

- **Provider rights:** only documented endpoints are called (`/v1/tracks/search`,
  `/v1/tracks/trending`, `/v1/tracks/{id}/stream`) with the documented identity (`app_name` +
  a product `User-Agent`); no undocumented parameter, host rotation or scrape exists. The
  resolver refuses a `Restricted` source before any socket (asserted live: the restricted case
  added zero requests to the log), never follows a redirect, never sends a signature or token,
  and answers a gated track with the typed refusal rather than a substitute copy.
- **No credential anywhere:** the secret scan (verify step `secrets`, tracked files *and* history)
  is green; `AudiusApi.apiKey` is a null-default constructor parameter (ADR-017) and ADR-019
  records that anonymous reads work, so no key was ever needed.
- **Stream URLs are never stored:** `RemoteLibraryWriter` has no field that could hold one, which
  is the phase document's named "common trap"; the reference carries only this app's 10-minute
  re-resolution budget (ADR-018).
- **Rate limits:** the live smoke makes seven requests per run, 600 ms apart, under the documented
  10 req/s; contract tests use MockWebServer precisely so CI never touches the provider. CI safety
  was re-verified this audit (the suite skips without the flag).
- **Privacy:** no analytics, no upload. Evidence logs print scheme + host + path only — never a
  query string, since a stream URL's query can carry a signature — plus UTC timestamps and an
  explicit `device-serial=none` line instead of a fabricated serial.
- **Accessibility:** the inspector's states are text (status, badges, feedback sentences), not
  colour alone; the failure and feedback lines use `error` colour *and* words; buttons carry
  text labels. No screen reader has ever announced any of it (deferred with the rest of the
  device proof).
- **Offline behaviour:** local playback does not read the network; discovery failure states are
  typed and retryable, and a provider failure cannot poison local playback (phase-02 regression
  suites still green).
